# Class3D Gallery v1.2

把同一台展覽電腦變成不需要後端的多媒體展覽館。圖片、影片、音訊、PDF、GLB／GLTF 可一次選取或拖放到瀏覽器，自動建立作品卡、分類與展示；作品檔、按讚、留言及展覽設定都不會上傳到伺服器。

線上展場：<https://polik18.github.io/class3d-gallery/>

## 展覽電腦操作

1. 按「選擇多媒體作品」，或把所有作品拖到右側展台。
2. 確認作品卡後，可按「保存目前作品」寫入這台電腦的 IndexedDB。下次開啟同一瀏覽器會自動恢復。
3. 在「展覽設定」輸入展覽總標題、副標題、介紹、班級與策展人，並調整訪客互動及自動展示秒數。
4. 可切換全展、分類展、自選展、獨展，以及座號／序號、分類、匯入時間、人氣、手動順序或名稱排序。
5. 按「展示預覽」可立即檢查自動展示；無人操作 30 秒後也會自動開始。

建議使用最新版 Chrome 或 Edge。Safari 可使用一般多檔選取；資料夾拖放能力依瀏覽器版本而異。

## 支援格式

- 圖片：瀏覽器可解碼的常用格式，例如 PNG、JPEG、WebP、GIF
- 影片：瀏覽器可播放的 MP4、WebM 等格式
- 音訊：瀏覽器可播放的 MP3、WAV、OGG 等格式
- 文件：PDF
- 3D：GLB，以及連同 `.bin`／貼圖一起選取的 GLTF

GLB 最適合攜帶與展示。GLTF 若遺漏相依檔會顯示錯誤；外部網址相依資源不會自動下載。

## 檔名就是作品資料

普通檔名去除副檔名後，會直接成為作品名稱與預設介紹。需要結構化資料時可使用雙底線：

```text
座號12__未來城市__王小明__使用回收材料製作.glb
序號04__海邊的一天__李同學__攝影作品.jpg
```

可辨識半形／全形數字及 `座號`、`序號`、`編號`、`No.` 前綴。沒有編號的檔案仍可展示。

## 3D 操作

- 左鍵拖曳：旋轉
- 滾輪或雙指：拉近／拉遠
- 右鍵拖曳：平移
- 「重設視角」：回到自動取景位置
- 「自動旋轉」：切換展台旋轉
- 模型含 animation clips 時，可播放或暫停內建動畫

## 訪客互動與人氣

- 每個本機訪客 session 可按讚，也可取消。
- 「下一位訪客」會建立新的本機 session，適合同一台展覽電腦輪流參觀。
- 留言可設定成送出後先待教師核准；教師可核准或刪除。
- 互動資料可匯出 JSON，留言可匯出 CSV，也可單獨清除。
- 人氣依本機按讚、已核准留言、人工瀏覽、互動與停留時間計算。
- 自動展示的瀏覽與停留不會增加人工人氣。

## 自動展示流程

預設在最後一次點擊、按鍵、觸控、滾動或輸入後 30 秒開始：

1. 展覽標題：6 秒
2. 作品輪播：90 秒；圖片 8 秒、3D 12 秒、影片最長 30 秒
3. 全體縮圖：20 秒
4. 人氣精選：30 秒
5. 回到標題並持續循環

任何人工操作都會立即退出。系統啟用「減少動態效果」時，展場會停用大幅轉場。所有時間都可在「展覽設定」調整。

## 本機保存、備份與隱私

- 未按「保存目前作品」時，作品只存在目前頁籤的記憶體與 Object URL。
- 保存後，原始二進位檔與作品資料寫入同一瀏覽器的 IndexedDB；重新載入會自動恢復。
- 「匯出展覽檔」會產生 `.c3dg` 本機備份，可在另一個瀏覽器用「匯入展覽檔」還原。
- 展覽設定、按讚及留言使用這台電腦的瀏覽器儲存空間。
- GitHub Pages 只提供靜態程式；程式沒有作品上傳 API、帳號系統或跨裝置同步。
- 清除網站資料、使用無痕模式或更換瀏覽器會失去本機資料；正式展覽前請匯出備份。

## 本機開發與驗證

需要 Node.js 22：

```bash
npm ci
npm run dev
```

完整品質門檻：

```bash
npm test
npm run check
npm run build
npm run project:validate
```

專案施工狀態不依賴對話紀錄。CLI agent 接手時先執行：

```bash
npm run project:status
git status --short --branch
```

權威狀態位於 `project/checkpoint.json`，目前交接位於 `project/handoffs/current.md`，每階段驗證證據位於 `project/evidence/`。

## 發布

推送 `main` 後，`.github/workflows/static.yml` 會依序執行安裝、型別檢查、完整測試、Vite 建置及 GitHub Pages 部署。Vite base 固定為 `/class3d-gallery/`。

# Class3D Gallery v1.2

班級作品 3D 展示平台。使用者可從本機選擇 GLB／GLTF 作品，直接在瀏覽器中互動展示；檔案不會上傳到伺服器。

## 本機啟動

```bash
npm install
npm run dev
```

正式建置與型別檢查：

```bash
npm run check
npm run build
```

## 目前狀態

已具備：

- 本機 GLB／GLTF 選檔與拖放載入
- 旋轉、縮放、平移及重設視角
- 模型內建動畫播放／暫停
- 自動旋轉與自動取景
- 教師/學生角色模型
- Dashboard 統計架構
- 作品分享 URL
- 學生個人頁資料模型
- 展示模式切換

## 操作方式

- 左鍵拖曳：旋轉
- 滾輪或雙指：拉近／拉遠
- 右鍵拖曳：平移
- `重設視角`：回到模型載入時的自動取景位置
- `自動旋轉`：切換展台旋轉
- 模型含有 GLTF animation clips 時，可播放或暫停動畫

GLB 是建議格式。若使用 GLTF，請在檔案選擇器中同時選取它引用的 `.bin` 與貼圖檔。

目前班級、學生及作品卡片仍使用示範資料；正式登入、作品目錄與跨裝置分享尚未實作。

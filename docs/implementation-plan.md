# Class3D Gallery v2 實施計畫

基線：`d64143c0ae7a68b4d272bb2224b0cbd395cfe097`。

目標是把現有單一 3D Viewer 擴充為瀏覽器本機多媒體展覽館，支援批次匯入、自動分類、檔名介紹、全展／分類展／自選展／獨展、排序、展覽總標題、按讚、留言、人氣及閒置自動展示。所有作品與互動資料只保存在同一台展覽電腦。

## 階段

| 階段 | 比重 | 內容 |
|---|---:|---|
| P00 | 8% | 可恢復 checkpoint、task manifest、handoff 與 CLI 狀態工具 |
| P01 | 8% | 多媒體作品與展覽資料模型 |
| P02 | 10% | 多檔／資料夾拖放與匯入佇列 |
| P03 | 8% | 自動分類、檔名／座號解析與 GLTF 相依檔 |
| P04 | 10% | IndexedDB 本機作品庫、容量與匯出／清除 |
| P05 | 16% | 圖片、影片、音訊、PDF、3D Renderers |
| P06 | 12% | 全展、分類展、自選展、獨展及多種排序 |
| P07 | 6% | 展覽總標題、副標題、介紹與教師設定 |
| P08 | 8% | 本機按讚、留言、審核與人氣 |
| P09 | 6% | 閒置輪播、縮圖牆、熱門展與動畫 |
| P10 | 5% | 效能、無障礙、安全與瀏覽器相容性 |
| P11 | 3% | 完整回歸、文件、發布及線上驗收 |

## 固定架構界線

- 不實作後端與 QR 跨裝置互動。
- Session 預覽使用 Object URL；選擇保存時才寫入 IndexedDB。
- 人氣只計算人工開啟、有效觀看、按讚、核准留言與實際操作；輪播不計分。
- 影音與 WebGL 只在焦點作品啟動，離開後必須暫停並釋放資源。
- `project/checkpoint.json` 與 Git 證據共同決定施工狀態，對話文字不能取代驗收。

完整 task、依賴及驗收條件見 `project/task-manifest.json`。

# P01-T01：多媒體作品與展覽資料模型

建立可序列化的 AssetRecord、Exhibition、排序、互動與展示狀態型別。完成單元測試後進入 P02。

## 已完成

- `AssetRecord` 涵蓋來源檔描述、媒體 metadata、座號、分類、排序、人氣與保存狀態。
- 一般檔名去除副檔名後，預設成為作品名稱與介紹。
- `ExhibitionSettings` 涵蓋展覽總標題、本機互動開關與自動展示時間。
- 建立資產集合與展覽設定的序列化、讀回及錯誤拒絕。
- 7 項 domain tests 通過；證據見 `project/evidence/P01-T01/verification.json`。

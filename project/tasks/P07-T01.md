# P07-T01：展覽總標題與教師設定

提供展覽標題、副標題、介紹、班級與顯示選項，保存於本機並套用到所有展示模式。

## 已完成

- 教師可編輯展覽總標題、副標題、介紹、班級與策展人。
- 可控制副標題、介紹、班級／策展人、作品數量與分類文字是否顯示。
- 輸入時即時預覽；按保存才寫入 localStorage，關閉會撤銷未保存內容。
- 保存後會同步套用到瀏覽器標題列、頁首、主展台與作品區，重新整理後仍保留。
- 全展、分類展、自選展與獨展均顯示相同展覽標題。
- 空白標題安全拒絕；舊版設定自動補齊，損壞設定恢復預設。
- 恢復預設只移除展覽設定自己的 key，不影響作品或其他本機資料。
- 全專案 56 項測試、桌面 Chrome 設定流程與 390px 手機版視窗皆通過；證據見 `project/evidence/P07-T01/verification.json`。

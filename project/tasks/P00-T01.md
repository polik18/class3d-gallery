# P00-T01：建立可恢復的 CLI 施工控制層

## 目標

建立不依賴對話 session 的 manifest、checkpoint、handoff、事件日誌與 CLI 指令，讓 Agent 中斷後可以從 repo 狀態繼續。

## 範圍

- repo 專屬 `AGENTS.md`
- 固定 task manifest 與 checkpoint schema
- checkpoint 原子寫入與 append-only journal
- `project:status`、`project:validate`、`task:start`、`task:checkpoint`、`task:finish`
- 中斷、過期 lease、損壞暫存檔與讀回測試

## 不處理項目

- 多媒體匯入與 UI 功能
- IndexedDB 作品庫
- 後端或跨裝置同步

## 開始前基線

`d64143c0ae7a68b4d272bb2224b0cbd395cfe097`

## 驗證命令

```bash
npm run project:validate
npm run test:project
npm run check
npm run build
```

## 完成條件

- 所有命令 exit 0。
- 模擬中斷後能讀回 `IN_PROGRESS`、`next_step` 與 lease 狀態。
- checkpoint 更新不會留下半寫 JSON。
- handoff 可由 checkpoint 與 manifest 重建。

## 已完成

- 建立固定 manifest、checkpoint、schema、handoff、journal 與 repo 專屬 `AGENTS.md`。
- 建立狀態查詢、驗證、任務開始、checkpoint 與驗收指令。
- 建立 9 項 Node 測試，涵蓋原子寫入、中斷讀回、lease、並行寫入序列化與狀態不一致拒絕。

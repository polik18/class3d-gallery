# P05-T01：多媒體 Renderer

建立圖片、影片、音訊、PDF 與 3D Renderer；離開焦點時停止播放並釋放 Object URL、貼圖及 WebGL 資源。

## 已完成

- 統一媒體舞台可從同一個選檔或拖放入口顯示圖片、影片、音訊、PDF、GLB 與 GLTF。
- 影片與音訊使用瀏覽器原生控制；PDF 使用同頁嵌入預覽。
- 3D 支援旋轉、縮放、平移、重設、自動旋轉及模型內建動畫。
- GLTF 可綁定同批匯入的 BIN 與貼圖；外部網址資源維持禁止連線下載。
- Renderer session 在切換作品時銷毀上一件；頁籤隱藏時暫停，pagehide 時清理。
- Object URL、媒體來源、Three.js 幾何、材質、貼圖、控制器與 WebGL renderer 均有明確釋放流程。
- Three.js 改為 3D 作品出現時才動態載入，初始 JS chunk 約 16.34 kB。
- 全專案 41 項測試與 Chrome 五媒體實測通過；證據見 `project/evidence/P05-T01/verification.json`。
